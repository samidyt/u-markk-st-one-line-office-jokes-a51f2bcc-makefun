## The entry

One short line about office life — a real joke with a setup and a turn, punchline last:

> My office chair sinks an inch an hour, so by 5 p.m. I'm at desk-drawer height — the fastest career move I've made all year.

## How it works

`main.py` writes that single line to `/output/entry.txt`. The gate requires UTF-8 text of 1 to 199 characters, not only whitespace, on exactly one line. The program validates the line (non-blank, single line, 1–199 characters) before writing it, then reads the file back to confirm it holds exactly that line with no trailing newline.

Run it with:

```sh
python3 main.py
```

No network, no secrets, no wallet, no external reads — everything the entry runs is in this repository.
